# TaskMatrix

TaskMatrix is a modern Agile project management platform designed to help teams manage projects, tasks, priorities, and progress in one place.

## Project Information

- **Project Name:** TaskMatrix
- **Designated Track:** Track A — Frontend Specialists
- **Project Type:** Agile Project Management Platform

## Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Redux Toolkit
- REST API
- MongoDB
- Git & GitHub
- Figma

## Core Features

### P0 — MVP
- User Authentication
- Project Dashboard
- Project Management
- Task Management
- Task Status Tracking
- Priority Management

### P1 — Advanced Features
- Interactive Kanban Board
- Project Details View
- Task Details View
- Search and Filtering
- Responsive UI/UX
- Global State Management

### P2 — Stretch Goals
- System Architecture
- Redux State Tree
- MongoDB Data Model / ERD
- Mock API Integration
- Performance Optimization

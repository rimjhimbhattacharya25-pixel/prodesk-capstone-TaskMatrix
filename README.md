# TaskMatrix

## Project Overview

TaskMatrix is a modern Agile project management platform designed to help teams organize projects, manage tasks, collaborate with team members, and track project progress from a centralized workspace.

## Problem Statement

Managing projects through scattered tools can make it difficult to track tasks, deadlines, priorities, team responsibilities, and overall progress. TaskMatrix provides a single platform where users can manage these activities efficiently.

## Objectives

- Manage projects and tasks from one centralized platform.
- Track task status, priority, and deadlines.
- Monitor project progress.
- Improve team collaboration.
- Provide a clean and intuitive user experience.
- Reduce complexity in Agile project management.

## Target Users

- Students working on team projects
- Software development teams
- Project managers
- Startup teams
- Small and medium-sized organizations

- Create tasks

### Project Owner
- Create and manage projects
- Manage tasks

### Team Member
- View assigned tasks
- Update task status
- Track project progress
- Collaborate with the team

## Functional Requirements

1. Users should be able to sign in.
2. Users should be able to access the dashboard after authentication.
3. Users should be able to navigate to the Projects section.
4. Users should be able to view project details.
5. Users should be able to view recent tasks.
6. Users should be able to view project progress.
7. Users should be able to view team members.
8. Users should be able to track project deadlines.
9. Users should be able to manage task status and priorities.

## Non-Functional Requirements

- Responsive and user-friendly interface
- Fast and reliable performance
- Maintainable and scalable architecture
- Secure authentication
- Consistent UI design
- Accessible navigation

## UI/UX Design

The initial UI/UX design consists of three primary screens:

1. Authentication
2. Dashboard
3. Project Details

The prototype connects these screens to demonstrate the primary user flow:

**Authentication → Dashboard → Project Details → Dashboard**
